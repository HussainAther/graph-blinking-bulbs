# Roadmap

## v0.1 — deterministic excitable graph
- synchronous updates
- OFF / ON / REFRACTORY states
- threshold activation
- path, ring, and star graph constructors
- reproducible tests and examples

## v0.2 — richer transmission
- weighted edges
- edge delays
- probabilistic transmission
- heterogeneous node thresholds
- node and edge failures

## v0.3 — analysis
- automatic cycle detection
- extinction time
- propagation speed
- synchronization score
- reachability and coverage metrics

## v0.4 — visualization
- animated network view
- state timelines
- collision visualization for two-source stimulation

## Research direction
Enumerate small connected graphs and search for topologies that produce
persistent or periodic blinking under fixed local rules.
